Before saving or activating anything, identify and preserve the exact key that encrypted existing employee records: an earlier dedicated employee/session key, or the unchanged legacy HIGHLEVEL_API_KEY. Keep that exact historical key as EMPLOYEE_HUB_DATA_SECRET. Never use a new random key for old employee data; resolve the original key first so those records remain readable.

# Ad Factory: download

This branch only hosts the download for **Ad Factory**, Easy Garage Cleaning's internal ad editing app.
It is separate from the website code on `main`.

## ⬇ [Download ad-factory.zip](https://github.com/zacbezenek-ctrl/Easy-Garage-Cleaning/raw/ad-factory-download/ad-factory.zip)

1. Unzip it somewhere permanent (e.g. Documents).
2. **Mac:** double-click `Start Ad Factory (Mac).command`. If it's blocked: on macOS 15 or newer go to System Settings → Privacy & Security → **Open Anyway**; on older macOS right-click → Open → Open.
   **Windows:** double-click `Start Ad Factory (Windows).bat` (if SmartScreen appears: More info → Run anyway).
3. The first launch installs what it needs (5-10 min), then the editor opens in your browser.
   Keep the small terminal window open while you work.

No account or sign-up. Everything runs on your computer.
The full guide is in `README.md` inside the zip, and the **?** button in the app has a tour and a feature guide.
